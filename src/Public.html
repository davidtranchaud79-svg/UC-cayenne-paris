Mes réponses enregistrées

Préparons les rendez-vous de la Cayenne

Ce logiciel permet au bureau d’organiser les réunions, les repas et les équipes d’aide. Il constitue l’unique outil pour enregistrer vos excuses.

Comment faire ? Connectez-vous avec votre code personnel, répondez sous chaque événement puis cliquez sur Enregistrer mes réponses. Vous pouvez répondre à plusieurs rendez-vous en une seule fois.

Un doute ? Choisissez « Je ne sais pas encore ». Rouvrez ce même lien avec votre code pour modifier votre réponse à tout moment et ajuster votre présence.
