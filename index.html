Important

Cette page GitHub sert de porte d’entrée. L’application ne peut pas fonctionner seule ici, car elle dépend de Google Apps Script et du Google Sheet.

Le lien membres est public : ouvrir le formulaire.

Le lien bureau est séparé et protégé par code : ouvrir le dashboard admin.

Installation rapide

  1. Ouvrir le Google Sheet.
  2. Aller dans Extensions > Apps Script.
  3. Coller l’onglet CODE_GS dans Code.gs.
  4. Créer trois fichiers HTML : Index, Public, Admin.
  5. Coller les onglets INDEX_HTML, PUBLIC_HTML, ADMIN_HTML.
  6. Lancer setupSystem.
  7. Déployer en application Web.
